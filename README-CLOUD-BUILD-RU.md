# LocalSkins — облачная сборка

Minecraft 1.16.5 + Fabric. Клавиша по умолчанию — F7; её можно изменить в Minecraft: Настройки → Управление → Назначение клавиш → LocalSkins. Язык интерфейса берётся из языка Minecraft (добавлены `ru_ru` и `en_us`).

Скины хранятся в `.minecraft/CustomSkins`. Щёлкните по строке скина, чтобы применить его; значок ✎ справа открывает отдельное окно переименования. «Обновить список» заново читает папку и нужен после ручного копирования файлов; сам по себе он скин не применяет. «Скачать и надеть» скачивает PNG по прямой HTTP(S)-ссылке, сохраняет его в `CustomSkins` и сразу применяет. Ссылка на страницу NameMC — это HTML-страница, а не PNG, поэтому сначала откройте каталог NameMC и получите прямую ссылку на файл изображения; автоматическое извлечение PNG со страницы NameMC в этой версии не реализовано.

Поддерживаются PNG 64×64 и legacy 64×32. Если на конкретном скине видны пустые/неверные области, нужен сам PNG для проверки UV-развёртки; эта сборка не гарантирует исправление всех некорректных текстур.

## Сборка на GitHub

Загрузите файлы проекта в репозиторий, затем откройте Actions → Build LocalSkins. После сборки скачайте артефакт `LocalSkins-1.0` и положите JAR в `.minecraft/mods`. Файл `.github/workflows/build.yml` включён в архив (папка скрытая).

Изменены `SkinSelectScreen.java`, добавлен `RenameSkinScreen.java`, обновлён `GameMenuScreenMixin.java`, локализации `ru_ru.json` и `en_us.json`, а также этот README. `LocalSkinManager.java` оставлен без изменений; загрузка применяет файл после завершения скачивания через клиентский поток. Сборка/запуск в Minecraft в этой среде не подтверждены — проверьте результат GitHub Actions перед тестированием.
