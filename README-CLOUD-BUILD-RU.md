# LocalSkins — сборка в облаке без установки программ на ПК

## Получение JAR через GitHub Actions

1. Войдите в GitHub или создайте бесплатный аккаунт: https://github.com/
2. Создайте новый репозиторий (кнопка **New**). Можно выбрать **Private**.
3. Распакуйте архив и загрузите содержимое папки `localskins` в корень репозитория. Важно: папка `.github/workflows/build.yml` тоже должна быть загружена. Если загружаете файлы через браузер, удобнее использовать GitHub Desktop на другом устройстве или веб-загрузку файлов; скрытые файлы `.github` должны сохраниться.
4. Откройте вкладку **Actions** репозитория. Если GitHub просит разрешить Actions, подтвердите.
5. Выберите **Build LocalSkins** → **Run workflow** → **Run workflow**. При загрузке в `main`/`master` сборка также запускается автоматически.
6. Откройте завершившийся запуск (зелёная галочка). Внизу страницы найдите **Artifacts** и скачайте `LocalSkins-1.0`.
7. Распакуйте скачанный архив. Файл `.jar` поместите в `%appdata%\.minecraft\mods` (Windows), затем запустите профиль Fabric для Minecraft 1.16.5.

Если сборка красная (failed), откройте её и скопируйте последние строки ошибки из шага **Build mod**. Это означает, что проект нужно исправить; не устанавливайте несуществующий или неполный JAR.

Примечание: это workflow для сборки исходников. Он не гарантирует, что мод корректно работает в игре; требуется тест запуска на Fabric 1.16.5.
