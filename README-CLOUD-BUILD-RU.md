# LocalSkins — облачная сборка

Minecraft 1.16.5 + Fabric. Клавиша открытия: F7. Папка локальных скинов: `.minecraft/CustomSkins`.

В окне мода можно фильтровать список по имени, переименовывать выбранный PNG, открыть папку, обновить список и скачать изображение по прямой HTTP(S)-ссылке на PNG (ссылка на HTML-страницу сайта не подходит). Поддерживаются PNG 64x64 и legacy 64x32.

Для сборки загрузите содержимое проекта в GitHub, откройте Actions → Build LocalSkins → Run workflow, затем скачайте артефакт `LocalSkins-1.0` и положите JAR в `.minecraft/mods`. Сборка исходников не заменяет проверку запуска в Minecraft.


Дополнения в этой версии: кнопка Local Skins в меню паузы опущена ниже; выбор файла заполняет поле переименования и передаёт ему фокус; загрузка проверяет размер скина (64×64 или 64×32); исправлено размещение текстур левой ноги для legacy 64×32. Полный рендеринг конкретных 64×64 текстур зависит от корректной UV-развёртки самого PNG.
